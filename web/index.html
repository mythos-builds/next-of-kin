Next of Kin

Crypto has no next of kin. Now it does.

A dead man's switch for Bitcoin Cash, written in SolidCash and running on mainnet. The owner's coins wait in a contract; the owner checks in now and then. If they go quiet, anyone can sound the warning, and if they still say nothing, anyone can release the coins: the contract pays each heir their share. Funds, never keys.

How it works

  1. Check in. Only the owner can. Each check-in re-spends the vault's state coin, so the coin's own age is the clock.
  2. Warn. Anyone, once the owner has been silent for silence blocks. The network itself refuses an early warning.
  3. Release. Anyone, grace blocks after the warning, if the owner did not check in. The contract pays heir A and heir B their shares, to the satoshi.
  4. Close. The owner can take everything back at any time.
